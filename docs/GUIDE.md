# GPUEnsemble 使い方ガイド

*[English](GUIDE.en.md)*

**手持ちの GPU を束ねて、1 枚では載らない大きな AI（LLM）を自分の PC で動かす。**

GPUEnsemble は、PC に挿さっている複数の GPU の VRAM を足し合わせて、1 枚には入りきらない大きな言語モデルを動かすソフトです。カードの種類や VRAM の大きさがばらばらでも使えます。別の PC の GPU を足すこともできます。

- **ダブルクリックで始まる。** PC の GPU・RAM・CPU を調べ、この PC で快適に動くうちいちばん賢いモデルを選び、ダウンロードして起動し、ブラウザにチャット画面を開きます。Python などを別に入れる必要はありません。
- **配置を自動で決める。** モデルのどの部分をどの GPU に置くか、入りきらない部分を RAM に置くかを、実際のモデルファイルと GPU の速さから計算します。llama.cpp の細かい引数を手で探す必要はありません。
- **別の PC の GPU も使える（試験段階）。** GPU のある PC がもう 1 台あれば、そちらでもダブルクリックするだけで、その GPU も一緒に使います。つなぐ PC は同じ家の LAN にあっても、離れた場所にあってもかまいません。離れた場所の PC とは、VPN でつなぎます。
- **手元で完結する。** モデルは自分の PC で動き、会話が外部のサービスに送られることはありません。ほかのアプリからは OpenAI 互換の API で使えます。

> **いまの状態: pre-alpha（試作段階）です。** 中身の計算には llama.cpp を使っており、GPUEnsemble 独自の実行エンジンはこれから作ります。動作を確認しているのは Windows と NVIDIA の RTX 20 系です。

## どれくらい動くか

開発に使っている PC での実測です（生成を続けたときの安定した速さ）。目安として、毎秒 5 トークン程度で人が読む速さくらいです。

| 構成 | モデル | 速さ |
| --- | --- | --- |
| RTX 2080 Ti + RTX 2080 SUPER（VRAM 計 19 GB）、RAM 64 GB | gpt-oss-120b（59 GiB） | 毎秒 約 6.5 トークン |
| 上の PC に、別の場所にある RTX 4090 の PC を VPN（Tailscale）経由で追加 | gpt-oss-120b | 毎秒 約 10〜10.7 トークン |
| RTX 2080 Ti 1 枚 | Qwen3-8B | 毎秒 約 80 トークン |

どちらの GPU にも 1 枚では入らない 59 GiB のモデルが、手持ちのカードを合わせることで動いています。計測の詳細は [benchmarks/](../benchmarks/README.md) にあります。

## 必要なもの

| 項目 | 内容 |
| --- | --- |
| OS | Windows 10 / 11（64 ビット） |
| GPU | NVIDIA の GPU。RTX 20 系で確認済みです。ドライバが CUDA 12.4 に対応していれば（551.61 以降）CUDA 版を使い、古いときは Vulkan 版を使います |
| RAM | 大きなモデルほど多く使います。gpt-oss-120b を選んだ開発機は 64 GB です |
| ディスク | モデルの大きさぶんの空き（約 5〜59 GiB）と、llama.cpp 用に約 1 GB |
| ネット | 最初にモデルと llama.cpp をダウンロードするときに使います |

どのモデルが選ばれるかは PC によって変わります。足りない構成でも、入る範囲でいちばん良いモデルを選びます。

## 使い始める（1 台の PC）

1. GitHub の Releases ページから、どちらかの zip をダウンロードします。中身はアプリ（`GPUEnsemble.exe`）があるかないかだけが違います。
   - `GPUEnsemble-<版>-windows-x64-app.zip`: ウィンドウのアプリ付き。`GPUEnsemble.exe` をダブルクリックすると、GPU・モデル・つながる PC を画面で見て、起動や停止ができます。
   - `GPUEnsemble-<版>-windows-x64-cli.zip`: アプリなし。下の `.cmd` とコマンドだけで使います。
2. 空き容量の多いドライブの、**英数字だけのフォルダ**に展開します（例: `D:\GPUEnsemble`）。日本語やスペースの入ったパスは避けてください。
3. `Start GPUEnsemble.cmd` をダブルクリックします（アプリ付きの zip なら `GPUEnsemble.exe` でもかまいません。下の「アプリで使う」）。
4. 黒いウィンドウが開き、PC を調べて使うモデルを決めます。ダウンロードの前に「download gpt-oss-120b MXFP4 (59.0 GiB) from Hugging Face? [Y/n]」のように大きさを聞いてくるので、よければ Enter を押します。
5. ダウンロードと読み込みが終わると、ブラウザにチャット画面（`http://127.0.0.1:8080/`）が開きます。

**初回は時間がかかります。** 大きなモデルはダウンロードに時間がかかり、起動のたびにモデルを RAM に読み込むので、gpt-oss-120b なら読み込みだけで 5 分ほどかかります。ダウンロードが途中で止まっても、もう一度ダブルクリックすれば続きから再開します。ダウンロードしたファイルは公表されているハッシュ値と照合します。

**止めるとき**は、ウィンドウで Ctrl+C を押します。最後のメッセージを読めるようにウィンドウは残るので、Enter で閉じてください。ウィンドウを直接閉じても、裏で動いていた llama.cpp は一緒に終わります。

**2 回目からは**同じようにダブルクリックするだけです。ダウンロード済みのモデルをそのまま使います。

## アプリで使う

`-app.zip` を展開したフォルダの `GPUEnsemble.exe` をダブルクリックすると、ウィンドウが開きます。

- **ホーム:** 使える GPU、おすすめのモデル、起動と停止、チャットを開くボタン。動いている間は実際の速さと、カードごとのメモリ・温度が出ます。
- **モデル:** 選べるモデルの一覧と予想速度。ダウンロード、起動、モデルの保存先の変更、「モデルを追加…」（Hugging Face の GGUF リポジトリをこの PC の一覧に加える）ができます。
- **つながる PC:** 別の PC の GPU を使う（メイン）か、この PC の GPU を貸すかを選びます。
- **ログ:** 裏で動いているコマンドの出力です。

ウィンドウを閉じても、通知領域のアイコンから開き直せます。表示の言語は Windows の言語に合わせて日本語か英語になり、左のメニューの下にある「English」/「日本語」で切り替えられます（次の起動でもその言語になります）。

## ほかのアプリから使う

起動している間、`http://127.0.0.1:8080/v1` が OpenAI 互換の API になります。OpenAI 用のライブラリやツールで、接続先をこのアドレスにすれば使えます。モデル名には、下の一覧の id（例: `gpt-oss-120b`）を指定します。

Qwen3 や gpt-oss は答える前に考える（推論のトークンを出す）ので、`max_tokens` が小さいと考えている途中で打ち切られて本文が空になります。多めに取ってください。

## モデルを選びたいとき

zip のフォルダにある `gpuensemble.cmd` をコマンドプロンプトや PowerShell から使います。

```
gpuensemble.cmd recommend                     この PC で動くモデルと予想速度の一覧
gpuensemble.cmd models                        選べるモデルと、ダウンロード済みかどうか
gpuensemble.cmd up --model qwen3-8b          モデルを指定して起動
gpuensemble.cmd up --model D:\models\x.gguf   手元の GGUF ファイルを使う
```

選べるモデルは、確かめた 49 種類（小さいものは Qwen3.5-4B の 2.5 GiB、大きいものは数百 GiB）と、Hugging Face で見つかった新しいモデルです。一覧は `gpuensemble.cmd models` で見られ、`gpuensemble.cmd catalog --update` で新しくなります（アプリは起動するたびに自分で新しくします）。どれが動くかは PC の GPU と RAM で決まり、`recommend` は動くものだけを予想速度つきで並べます。一覧にない GGUF のモデルは `gpuensemble.cmd catalog --add <Hugging Face のリポジトリ名>` で、その PC の一覧に加えられます。

コマンドの詳しい説明は [planner/README.md](../planner/README.md) にあります。

## 別の PC の GPU も使う（試験段階）

GPU のある PC がもう 1 台あれば、その GPU も合わせて使えます。

### 同じ家の LAN にある場合

1. GPU を貸す PC にも同じ zip を展開し、`Start GPUEnsemble worker.cmd` をダブルクリックします。
2. メインの PC で `Start GPUEnsemble.cmd` をダブルクリックします。メインの PC は LAN の中から貸す PC を自動で見つけます。
3. 初めてつなぐときは、貸す PC のウィンドウに「PC '（メインの PC の名前）' at （アドレス） asks to use these GPUs」と表示されます。`y` を入力して Enter を押すと、その PC に GPU を貸します。一度許可すると次からは聞かれません。

メインの PC は、この許可を最大 2 分待ちます。Windows が Python の通信を許可するか聞いてきたら、**プライベート ネットワークだけ**を許可してください。見つからないときは、貸す PC のウィンドウを見てください。ネットワークがパブリック扱いになっているなど、届かない理由があれば `note:` で知らせます。

### 離れた場所にある場合

離れた場所の PC とは、VPN でつないでから使います。2 台が同じ VPN に入っていれば、あとは LAN の場合とほぼ同じです。

1. GPU を貸す PC で `Start GPUEnsemble worker.cmd` をダブルクリックします。
2. メインの PC で、貸す PC の VPN のアドレスを指定して起動します（例: `gpuensemble.cmd up --remote auto:10.0.0.2`）。
3. 初めてつなぐときは、貸す PC のウィンドウで `y` を入力して Enter を押し、許可します。

離れた場所の PC は、自分の担当する部分のモデルを Hugging Face から自分でダウンロードするので、メインの PC の回線の上りが遅くても待たされません。

VPN に Tailscale を使う場合は、もっと簡単です。2 台が同じアカウントでログインしていれば、メインの PC は `Start GPUEnsemble.cmd` のダブルクリックだけで貸す PC を見つけ、`y` を押さなくてもつながります。

### 知っておくこと

- 貸す PC は受け取ったモデルを保存しておくので、2 回目からは起動が速くなります。
- 別の PC との通信に時間がかかって速くならないときは、その GPU を使わない配置が選ばれます。
- モデルが貸す PC 1 台の GPU に丸ごと収まり、そのほうが速いときは、貸す PC がそのモデルを自分でダウンロードして動かし、メインの PC はチャットの画面と API を中継します。使い方は変わりません。
- 開発機の実測では、別の場所の RTX 4090 を VPN（Tailscale）経由で足して、gpt-oss-120b が毎秒 約 6.5 トークンから約 10 トークンになりました。そのときの初回の起動は約 8 分でした（[計測](../benchmarks/phase2b-two-sites-tailscale.md)）。

## 安全について

GPU を貸す仕組み（llama.cpp の RPC）には、パスワードも暗号化もありません。そこで GPUEnsemble は、許可した PC のアドレスからの接続だけを通す門番を前に置いています。

- 家庭の LAN、2 台を直結したケーブル、VPN のような**信頼できるネットワークだけ**で使ってください。
- 貸す PC のポート（50052 から 50054）をインターネットに公開しないでください。
- チャット画面と API（`127.0.0.1:8080`）は、その PC の中からだけ使えます。

詳しくは [SECURITY.md](../SECURITY.md) を見てください。

## 困ったとき

- **ダウンロードが止まった:** もう一度ダブルクリックすると続きから再開します。空き容量が足りないときは、始める前に止まります。
- **llama.cpp が起動直後に落ちる:** Visual C++ のランタイムが古いと起きます。GPUEnsemble がほかのアプリから新しいものを見つけて自動で直しますが、見つからないときは案内に従って Visual C++ 再頒布可能パッケージを入れてください。
- **別の PC が見つからない:** 「別の PC の GPU も使う」の、ファイアウォールとネットワークの種類の説明を見てください。

## アンインストール

モデルも llama.cpp も、すべて展開したフォルダの中の `data` に入ります。フォルダごと削除すれば、何も残りません。

モデルだけ別のドライブに置きたいときは、アプリ（`GPUEnsemble.exe`）のモデル画面の「モデルの保存先」で「変更…」を押してフォルダを選びます（コマンドでは環境変数 `GPUENSEMBLE_MODELS` にフォルダを指定します）。変えても、ダウンロード済みのモデルは移動しません。
